Bonanza
Transportation.

— full-stack booking platform.

Next.js 15 TypeScript Supabase Stripe Twilio Maps API Vercel

A premium transportation service had no way for customers to book online. I built one — from the database up to the Stripe receipt — by myself.

Architected the whole system from zero: schema, payment flow, SMS confirmations, deployment. Started with the boring docs (System Design, ERD, service-layer class diagram, MVP use cases) so the build itself stayed tightly scoped.

Configured a real engineering workflow on top — GitHub Org with branch protection, Vercel CI/CD, custom domain on Google Workspace — because shipping a one-person project should still look like a team made it.

MOD · 02 Jun — Nov 2025 co-developer

Project
Zenith.

— AI streaming plugin for Jellyfin.

Python FastAPI REST C# / .NET Ollama

Bringing back the feeling of "what's on TV?" — for a self-hosted kids' library, with an LLM playing programming director.

Co-built a plugin that turns an on-demand Jellyfin library into a continuous, AI-curated live channel for children's content. I owned the backend — a Python/FastAPI service that the C# plugin talks to over REST.

The integration gap nobody had solved: Jellyfin couldn't natively serve the AI-scheduled stream. I engineered server-side video streaming straight from FastAPI to close it. All inference runs locally through Ollama — no external API in the loop.

MOD · 03 ongoing personal infra

The
Homelab.

— a hobby teaching me production Linux.

Proxmox Docker Linux · Fedora Nginx WireGuard NetBird

A Proxmox host running 20+ Docker containers — most of what I'd otherwise pay a SaaS for. The unglamorous parts of being an engineer.

A 6-service automation pipeline I built around Sonarr — chaining Prowlarr, qBittorrent (behind Gluetun/WireGuard), Bazarr, Shoko, and Jellyfin into one hardlink-based workflow.

Nginx Proxy Manager fronts everything with TLS; NetBird gives me mesh VPN access from anywhere. Along the way I've broken and fixed GPU passthrough, restructured NFS storage under load, and lost more than one VM to OOMs — which has done more for my Linux skills than any course.
